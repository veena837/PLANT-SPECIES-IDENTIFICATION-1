About This Project

This system identifies plant species from leaf images using a Convolutional Neural Network (CNN) built with TensorFlow/Keras and served with Flask. After prediction it shows the common name, scientific name, regions found in India, medicinal uses and a confidence score.

Developed by: Revati Neeralagi (U30WO23S0140)
Guide: Prof. Prathiba K, MCA
College: K.L.E Society's GH BCA College, Haveri

Medicinal information is for educational purposes only.
